
## 🤝 Kako doprinijeti (Upload novih datuma)?
Projekt je potpuno otvoren za sve povjesničare, suborce i entuzijaste! Ako želite dodati važne datume, herojstva, akcije ili svjetske događaje:
1. Napravite **Fork** ovog projekta.
2. Nadopunite datoteku `calendar.nob` novim datumima u formatu `mj kratica` (npr. `ruj 17`).
3. Pošaljite **Pull Request** kako bih pregledao i uvrstio vaše izmjene u glavnu bazu.
